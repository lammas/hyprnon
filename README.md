# non's hyprland setup

a three-column layout for wide displays

not really something to use as-is, but as an inspiration for your own thing.

## requires

- `hyprland >= 0.56`

*stuff that's hardcoded, but optional if you want it bad enough:*

- ghostty
- eva
- wofi
- waybar
- hyprlock
- hyprpaper
- grimblast
- obsidian
- firefox
